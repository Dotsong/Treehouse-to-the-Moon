# The cel kit

These two files come from the Maleficium repo (`workshop/src/cel-kit.js`, up to `makeMichelleCel`, and `workshop/cast/folk.js`) and are spliced into `index.html` on the `cel-style` branch by `tools/cel/splice.py`. They give the game Maleficium's look: three-band toon light (`celRamp`, `toon`), ink outlines, painted canvas textures, and the cel cast (`makeCelFolk`, `FOLK`).

To pick up later changes to the cast, copy the two files over from Maleficium again and run the splice on a fresh copy of `main`'s `index.html`.
